# Database product artwork

Locally bundled SVG brand marks used only to identify the corresponding connection engine. Artwork is not generated or approximated. No logo requests occur at runtime. All36registered engines have an explicit mapping in lib/engine-logos.ts.

See sources.json for exact upstream URLs, collection versions/commits, SHA256 hashes and applicable notices. Devicon original multicolor artwork is retained; Simple Icons paths use their published brand color. AWS marks come from the official July2026 architecture icon package. IBM Db2 uses IBM Carbon's product icon. Valkey, Weaviate and QuestDB use official website SVGs. Pinecone uses the unchanged standalone mark path from its official header SVG, without the adjacent wordmark. HANA uses SAP's brand mark; Oracle retains its original wordmark.

Collection licenses are included alongside these assets. Brand trademarks remain with their respective owners; collection licenses do not transfer trademark rights or imply endorsement. Do not substitute a generic database cylinder for a missing brand or automatically fetch remote artwork.

XML/DOCTYPE declarations were removed where present. SVGs were checked to exclude scripts, event handlers, embedded raster images, foreignObject and external resource references. Intrinsic artwork geometry/colors are preserved; display sizing and contrasting backgrounds are handled by CSS.
